# Changelog

## 2026.10 (2026-10-12): 2026 maintenance update

The printed version is tagged `first-edition`.

### Fixed
- `pip install -r requirements.txt` works: the file was missing. Added `pyproject.toml`, `uv.lock` and a pinned `requirements.txt` (Python 3.12+).
- `python main.py --ingest` rebuilds the DuckDB manifests instead of appending to them. A fresh clone used to end with 450 curated rows for 50 encounters.
- Reviewer UI (`/reviewer/{id}`) returned HTTP 500 on Starlette 1.x; it now uses the current `TemplateResponse(request, name, context)` call.
- `python main.py --setup` (called by `start.sh` and `demo.py`) is now an alias for `--ingest`.
- `semantic_api.py`: `eval()` replaced by `json.loads`; the vitals CSV path is passed as a SQL parameter.
- A fresh clone no longer fails on import when `data/processed/` or `static/images/` is missing.

### Changed
- `generate_raw_data.py` takes `--seed` (default 42).
- README follows the standard playbook layout. It describes encounter linking (shared ID from file names) and synthetic notes and vitals as the code implements them, and lists data licenses (ChestMNIST: CC BY 4.0).
- `src/ingestion.py` is marked legacy (not used by `main.py`).

### Removed from the tree (all regenerated by `--ingest`, or unused)
- `data/processed/granite_lite.db`, `static/images/*`, `src/__pycache__/*.pyc`
- 50 orphaned `data/processed/enc_*_vitals.csv` files, which nothing read

### Added
- `tests/test_smoke.py` and `make smoke`; GitHub Actions smoke test on Python 3.12 and 3.13.
- `.gitignore`, `.env.example` (no keys needed).
