# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| ChestMNIST (50 chest X-ray thumbnails, 28×28, with their 14 labels in the file names) | [MedMNIST v2](https://medmnist.com/), derived from the NIH ChestX-ray14 dataset (de-identified) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | `data/raw/images/` (200 KB) |
| Clinical notes (50) | Synthetic, generated from each image's labels by `generate_raw_data.py` | MIT (this repository) | `data/raw/notes/` (200 KB) |
| Vital signs (50 CSVs: HR, SpO2, RR) | Synthetic, generated by `generate_raw_data.py` | MIT (this repository) | `data/raw/vitals/` (400 KB) |

## Citations

- ChestMNIST: J. Yang, R. Shi and B. Ni, "MedMNIST Classification Decathlon: A Lightweight AutoML Benchmark for Medical Image Analysis", *IEEE ISBI*, 2021.
